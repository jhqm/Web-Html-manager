## 三、新预览内核设计要点

```
┌── App.vue ────────────────────────────┐
│   只持有 previewZoom 状态              │
│   :file-path / :zoom 透传给子组件      │
└──────────────┬────────────────────────┘
               ▼
┌── PreviewPane.vue ────────────────────┐
│ src = app://preview/<encoded path>    │
│ iframe.style:                          │
│   width: 100% / zoom                  │
│   height: 100% / zoom                 │
│   transform: scale(zoom)              │
│ 外层 viewport 负责滚动 / 拖拽          │
└──────────────┬────────────────────────┘
               ▼
┌── electron/main.ts ───────────────────┐
│ protocol.handle('app', ...)           │
│ → net.fetch(file://<本地路径>)         │
└───────────────────────────────────────┘
```

**核心数学保证**：iframe 反比尺寸 × scale(zoom) = 100% × 1，因此 **不论 zoom 多少，iframe 视觉占位永远 = viewport**，自然消除留白与"原尺寸反弹"。

